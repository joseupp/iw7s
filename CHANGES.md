# Historial de versiones

## r1000b — primera beta

Primera versión pública de IW7S. Incluye todas las novedades descritas en el [README](README.md): partidas públicas sin conexión con bots que se comportan como jugadores, texturas personalizadas, FOV del arma independiente, HUD ajustable, mensaje del día y más.

Las revisiones anteriores (r1000–r1113) fueron versiones alfa de desarrollo.

Desarrollado entre el autor de este repositorio y Claude (Anthropic).
